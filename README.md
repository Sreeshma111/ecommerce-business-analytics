# E-commerce Business Analytics Using Python

## Project Overview
This project focuses on analyzing the Brazilian Olist E-commerce dataset to understand business performance, customer behavior, sales trends, product performance, payment methods, delivery performance, and customer satisfaction.

## Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand customer purchasing behavior.
- Analyze popular payment methods.
- Evaluate delivery performance.
- Understand customer satisfaction through review scores.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses the Brazilian Olist E-commerce public dataset, which contains information about orders, customers, products, sellers, payments, reviews, and order items.

## Key Performance Indicators (KPIs)
- Total Orders: 99,441
- Total Sales: R$13,591,643.70
- Average Order Value: R$137.75
- Average Customer Rating: 4.09/5
- Average Delivery Time: 12.09 days

## Key Business Insights
- Health & Beauty generated the highest revenue.
- Credit card was the most commonly used payment method by payment value.
- Most orders were successfully delivered.
- Orders with 5-star reviews had the shortest average delivery time.
- Delivery performance is an important area for improvement.

## Business Recommendations
- Focus on high-revenue product categories.
- Improve delivery efficiency.
- Investigate low-rated customer experiences.
- Encourage customers to explore related products through bundles and cross-selling.

## Project Structure
- Dataset – Original and processed datasets.
- Notebook – Python analysis notebook.
- Dashboard – Power BI dashboard.
- Visualizations – Exported charts and graphs.

## Conclusion
This project demonstrates how Python-based data analysis can help businesses understand sales performance, customer satisfaction, product trends, and delivery operations. The findings provide useful insights to support better business decisions.
